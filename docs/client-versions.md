## 5. `官方` 目录的处置

**不要删**，它是分析补丁内容的唯一样本。改名隔离即可：

```powershell
ren "E:\源端\官方" "官方_已更新_20261127"
```

改名后任何脚本都不会误用它；需要对比补丁时再指回去。

## 6. 后续每次定版的口径

1. 只在 `pktmon` / `patchupdate` 无残留进程时定版。
2. 定版三件套：`gen-manifest.py` → 树指纹 → 冷备 7z + MD5，三者数字必须来自同一次扫描。
3. 版本号相同不代表内容相同，**指纹才是唯一标识**。
